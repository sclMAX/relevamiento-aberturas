# Relevamiento: software de cálculo de aberturas

Este repositorio publica una página temporal con una investigación preliminar y un cuestionario previo a una reunión de trabajo.
La página es un único archivo estático (`index.html`): no usa servidores, formularios remotos, analítica ni recursos externos.
El cuestionario se completa paso a paso (10 pasos, casi todo con opciones) y las respuestas se guardan solo en el navegador de quien responde hasta que esa persona decide descargarlas o enviarlas.
Para seguir en otro dispositivo se puede generar un "link para continuar": las respuestas viajan comprimidas dentro del propio link (después de `#`), que el navegador no envía a ningún servidor.
